PPO algorithm (with clipping, extending Actor-Critic)

Set β ≥ 0, entropy regularization weight
Set ε ≥ 0, the clipping variable
Set K, the number of epochs
Set N, the number of actors
Set T, the time horizon
Set M ≤ NT, the minibatch size
Set αA ≥ 0, actor learning rate
Set αC ≥ 0, critic learning rate
Randomly initialize the actor and critic parameters θA, θC
Initialize the “old” actor network θAold
for i = 1, 2, . . . do
    Set θAold = θA
    for actor = 1, 2, . . . , N do
        Run policy θAold in environment for T time steps and collect the trajectories
        Compute advantages A1, . . . , AT using θAold
        Calculate Vtarπ,1, . . . , Vtarπ,T using the critic network θC and/or trajectory data
    end for
    Let batch with size NT consist of the collected trajectories, advantages, and target V -values
    for epoch = 1, 2, . . . , K do
        for minibatch m in batch do
            The following are computed over the whole minibatch m
            Calculate rm(θA)
            Calculate JmCLIP(θA) using the advantages Am from the minibatch and rm(θA)
            Calculate entropies Hm using using the actor network θA
            Calculate policy loss:
            Lpol(θA) = JmCLIP(θA) − βHm

            Calculate predicted V -value Vˆ π(sm) using the critic network θC
            Calculate value loss using the V -targets from the minibatch:
            Lval(θC ) = MSE(Vˆ π(sm), Vtarπ(sm))

            Update actor parameters, for example using SGD:
            θA = θA + αA∇θA Lpol(θA)
            Update critic parameters, for example using SGD:
            θC = θC + αC∇θC Lval(θC )
        end for
    end for
end for
