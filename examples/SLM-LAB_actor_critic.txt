Actor-Critic algorithm


Set β ≥ 0 # entropy regularization weight
Set αA ≥ 0 # actor learning rate
Set αC ≥ 0 # critic learning rate
Randomly initialize the actor and critic parameters θA, θC
for episode = 0 . . . MAX_EPISODE do
    Gather and store data (st, at, rt, s0t) by acting in the environment using the current policy
    for t = 0 . . . T do
        Calculate predicted V -value Vˆ π(st) using the critic network θC
        Calculate the advantage Aˆπ(st, at) using the critic network θC
        Calculate Vtarπ(st) using the critic network θC and/or trajectory data
        Optionally, calculate entropy Ht of the policy distribution, using the actor network θA. Otherwise, set β = 0
    end for
    Calculate value loss, for example using MSE:
    Lval(θC ) = T1 P Tt=0(Vˆ π(st) − Vtarπ(st))2
    Calculate policy loss:
    Lpol(θA) = T1 P Tt=0(−Aˆπ(st, at)log πθA (at | st) − βHt)
    Update critic parameters, for example using SGD:5
    θC = θC + αC∇θC Lval(θC )
    Update actor parameters, for example using SGD:
    θA = θA + αA∇θA Lpol(θA)
end for
