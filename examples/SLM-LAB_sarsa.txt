SARSA algorithm

Initialize learning rate α
Initialize ε
Randomly initialize the network parameters θ
for m = 1...MAX_STEPS do
    Gather N experiences (si, ai, ri, s'i, a'i) using the current ε-greedy policy
    for i = 1 . . . N do
        # Calculate target Q-values for each example
        yi = ri + δs'i γ Q^πθ (s'i, a'i) where δs'i = 0 if s'i is terminal, 1 otherwise
    end for
    # Calculate the loss, for example using MSE
    L(θ) = (1/N) Σi(yi − Q^πθ(si, ai))^2
    # Update the network’s parameters
    θ = θ − α∇θL(θ)
    Decay ε
end for
